# mdAnything



An online, lightweight [Markdown smart editor](md.nero-lithos.com). Helps you generate LaTex maths, punctuation marks, tables, code blocks and many more with shortcuts and hotkeys. You can write and download on site, with preview and auxiliary line to help you format your work. In development progress ...

- **Compatibility Hint**: Tells you how your math blocks compat KaTex, MathJax, GitHub, markdown-it-texmath or other envs.

![CompatHint](https://i.postimg.cc/d0Hy1Nm4/jie-ping2026-05-09-10-12-10.png)

- **Downloadable**: as md/txt/pdf.
- **Math keyboard**: helps you fill in KaTex/LaTex math, e.g. matrices which are hard to write by hand.

![](https://i.postimg.cc/J4NHJz5n/jie-ping2026-05-09-10-56-19.png)

- **Table translator**: Builds or translates table (identifies two or more spaces as divided columns).
